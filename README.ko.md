# SOS My English

[English](README.md) | **한국어**

[![License: MIT](https://img.shields.io/badge/license-MIT-blue)](LICENSE)

말문이 막히나요? **영어 말하기**를 내 컴퓨터에서 연습하는 앱입니다. 주제를 고르고 AI 대화 상대와
소리 내어 이야기하면, 상대가 음성으로 답하고 내가 한 말을 바로바로 고쳐 줍니다.

[SOS My Interview](https://github.com/gyedongjeon/sos-my-interview)와 같은 SOS 시리즈입니다.

## 주요 기능
- **말하기 중심**: 타이핑이 아니라 목소리로 답합니다. 내가 한 말은 자동으로 받아 적힙니다.
- **듣기부터 연습**: 상대의 말은 음성으로 먼저 들려주고, 글자는 버튼을 눌러야 보입니다.
- **바로바로 교정**: 말할 때마다 가장 중요한 한 가지를 골라, 더 나은 문장과 이유를 보여 줍니다. 고친 문장은 음성으로 들어 볼 수 있습니다.
- **얼마나 또렷하게 말했는지**: 문장마다 명료도 점수, 잘 인식되지 않은 단어, 말하는 속도를 보여 줍니다.
- **한국어 설명**: 교정 설명은 한국어로 받을 수 있습니다. 대화는 영어 그대로입니다.
- **내 컴퓨터에서 실행**: 음성 인식과 상대 목소리는 컴퓨터 안에서 처리되고, 데이터도 내 컴퓨터에만 저장됩니다. 대화 글만 내가 고른 AI 서비스로 전송됩니다.

계정 가입이나 서버가 없는 1인용 앱입니다.

## 설치
설치 파일은 아직 없습니다. [소스에서 실행](README.md#run-from-source)할 수 있습니다.

## 처음 설정
앱을 처음 열면 Settings 화면이 나옵니다.

1. **Feedback language**: 교정 설명을 받을 언어를 고릅니다. 시스템 언어가 한국어면 한국어가 미리 선택되어 있습니다.
2. **AI model**: 사용할 AI 서비스(Provider)와 모델을 고르고, 그 서비스의 API 키를 붙여 넣은 뒤 "Save and test"를 누릅니다.

Google Gemini, Claude, OpenAI, OpenRouter 등을 쓸 수 있습니다. API 키는 내 컴퓨터에만 저장되고, 저장한 뒤에는 화면에 다시 표시되지 않으며, 선택한 서비스로만 전송됩니다.

## 사용 방법
1. **Practice**에서 주제를 고르면 상대가 첫마디를 읽어 줍니다. 못 들었다면 "Replay", 글자로 보고 싶다면 "Show text"를 누릅니다.
2. "Start speaking"을 누르고 말한 뒤 "Stop"을 누릅니다.
3. 내가 한 말과 교정이 나오고, 상대가 이어서 말합니다. 같은 식으로 대화를 이어 갑니다.
4. "Start over"로 같은 주제를 처음부터 다시 할 수 있습니다.
