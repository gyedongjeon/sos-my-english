## Request

Start `sos-my-english`, an English learning app centred on speaking, as the first branch of the
repository. It is released as a series product next to `sos-my-interview` and should be a
desktop app much like it, so that project's source may be reused freely.

## Changes

- **Reused from `sos-my-interview` (v0.2.1)**, renamed and otherwise unchanged: the SOS theme and
  brand components, the Settings page (feedback language, model and API key), the LiteLLM
  wrapper, local Whisper transcription, the local Kokoro voice with its cache and browser-voice
  fallback, the Electron shell with the bundled `uv`, the CI and release workflows, and the
  git-workflow documents, worklog template, and `AGENTS.md`. Environment variables use the
  `SOS_MY_ENGLISH_` prefix, and the version starts at `0.1.0`.
- **Left out**: everything specific to interviews (questions, attempts and history, résumé and
  job postings, scoring), the camera, and live captions. The dependencies only those needed
  (`lxml`, `pypdf`, `trafilatura`, `@types/dom-speech-recognition`) were removed, and the desktop
  app asks for the microphone only.
- **New: spoken conversation.** Topics are seeded in the database, each with a situation and the
  tutor's opening line (`GET /api/topics`). `POST /api/reply` takes the conversation so far and
  returns the tutor's next line with at most one correction of the learner's latest message; the
  correction is explained in the feedback language. One model call returns both, as JSON, to
  keep the wait between turns short. The conversation is kept in the page (a Pinia store) and is
  not saved yet; history was left for a later branch.
- **Practice page**: the tutor's line is read aloud and its text stays hidden until asked for;
  the learner records a reply, which is transcribed with its clarity, unclear words, and pace;
  the correction is shown under the learner's line and can be played. If the reply request
  fails, the learner's line is kept and the reply can be asked for again.
